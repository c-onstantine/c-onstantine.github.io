01-大模型微调概述

什么是大模型微调

大模型微调（Fine-tuning）是指在预训练大语言模型的基础上，使用特定领域或任务的数据进行进一步训练，使模型更好地适应特定场景的过程。

预训练 vs 微调

阶段 数据规模 计算资源 目标
预训练 海量数据（TB级） 极高（数千GPU） 学习通用语言知识
微调 特定领域数据（GB级或更少） 较低（单卡或多卡） 适应特定任务或领域

一个形象的比喻

  • 预训练：像一个人读完整个图书馆，获得广博的知识
  • 微调：像这个人经过专业培训，成为某个领域的专家

为什么需要微调

预训练模型的局限性

  1. 通用性强，专业性弱：预训练模型学习了大量通用知识，但在特定领域（医疗、法律、金融等）可能表现不佳
  2. 输出风格固定：模型的回答方式、语气相对固定，难以满足个性化需求
  3. 知识截止：预训练后无法获取新知识，存在知识时效性问题
  4. 行为对齐不足：模型可能生成不安全、不准确或不符合预期的内容

微调能做什么

1. 领域知识注入

让模型掌握特定领域的专业知识和术语：

  • 医疗领域：诊断建议、病历分析、药物交互
  • 法律领域：法规解读、合同审查、案例分析
  • 金融领域：财报分析、风险评估、投资建议
  • 技术领域：代码生成、技术文档、架构设计

2. 风格与角色定制

调整模型的输出风格，使其扮演特定角色：

  • 客服助手：友好、专业、问题导向
  • 教育导师：耐心、启发式、循序渐进
  • 创意写作：生动、有趣、富有想象力
  • 技术顾问：精准、简洁、代码优先

3. 任务适配

针对特定任务优化模型表现：

任务类型 示例
文本分类 情感分析、意图识别、主题分类
信息抽取 实体识别、关系抽取、事件抽取
文本生成 摘要生成、对话生成、代码生成
问答系统 知识问答、阅读理解、客服问答

4. 行为对齐

使模型输出更符合人类期望：

  • 安全性：避免生成有害内容
  • 准确性：减少幻觉和错误信息
  • 一致性：回答逻辑连贯
  • 有用性：提供实际帮助

微调的主要方法

全参数微调（Full Fine-tuning）

更新模型的所有参数，效果最好但资源需求最大。

参数高效微调（PEFT）

只更新少量参数，大幅降低资源需求。

LoRA（Low-Rank Adaptation）

在模型权重旁添加低秩矩阵，只训练这些小矩阵。

QLoRA（Quantized LoRA）

在 LoRA 基础上使用 4-bit 量化，进一步降低显存需求。

DoRA（Weight-Decomposed Low-Rank Adaptation）

将权重分解为幅度和方向两部分，分别优化。

Unsloth（2026 年新工具）

基于 LoRA 的优化实现，号称 2x 训练速度和 70% 显存降低。

方法对比（2025+ 最新数据）

方法 显存需求（7B） 训练速度 效果 适用场景
全参数微调 ~28-32 GB 慢 最佳 大规模训练
LoRA ~16 GB 快 良好 通用场景
QLoRA ~6 GB 较快 良好 消费级 GPU
DoRA ~16 GB 快 优秀 追求质量
Unsloth ~5 GB 极快 良好 追求效率

本章小结

  1. 微调定义：在预训练模型基础上，使用特定数据进一步训练，使模型适应特定场景
  2. 核心价值：注入领域知识、定制输出风格、适配特定任务、对齐模型行为
  3. 主要方法：全参数微调、LoRA、QLoRA、DoRA，各有优劣
  4. 工作流程：选模型 → 准备数据 → 配置训练 → 执行训练 → 评估优化 → 部署应用
